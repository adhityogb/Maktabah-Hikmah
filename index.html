Pasang di iPad

  1. Buka situs ini menggunakan Safari.

  4. Tekan Impor koleksi PDF, lalu pilih semua PDF dari aplikasi Files.

PDF disimpan di penyimpanan situs pada iPad dan tidak dikirim ke server. iOS dapat menghapus data situs ketika penyimpanan sangat penuh, jadi simpan file asli di aplikasi Files sebagai cadangan.
