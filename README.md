# Maktabah Hikmah

Maktabah Hikmah adalah PWA perpustakaan Islam pribadi yang dioptimalkan untuk iPad mini. Aplikasi menyimpan PDF yang dipilih pengguna langsung di perangkat melalui IndexedDB; file buku tidak diunggah ke GitHub Pages.

## Fitur

- PWA yang dapat dipasang dari Safari ke Home Screen
- Impor beberapa PDF sekaligus dari aplikasi Files
- Pencocokan otomatis untuk Tafsir Ibnu Katsir Jilid 1–8, Sejarah Al-Quran, 101 Kisah, dan Kumpulan Doa
- Penyimpanan buku secara lokal di perangkat
- Lanjutkan membaca, halaman terakhir, favorit, pencarian, dan tiga tema
- App shell tetap dapat dibuka tanpa internet

## Mengaktifkan GitHub Pages

1. Buka **Settings → Pages** pada repositori.
2. Pada **Build and deployment → Source**, pilih **GitHub Actions**.
3. Buka tab **Actions** dan jalankan workflow **Deploy Maktabah Hikmah** bila belum berjalan otomatis.
4. Situs akan tersedia di `https://adhityogb.github.io/Maktabah-Hikmah/`.

## Memasang di iPad

1. Buka situs melalui Safari.
2. Tekan **Share → Add to Home Screen**.
3. Buka ikon **Maktabah**.
4. Tekan **Impor koleksi PDF** dan pilih file PDF dari Files.

## Catatan penyimpanan

PDF disimpan pada penyimpanan situs di iPad. iOS dapat menghapus data situs ketika ruang penyimpanan sangat terbatas. Simpan file asli di aplikasi Files sebagai cadangan.
